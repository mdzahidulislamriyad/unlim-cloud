# ☁️ UnLim Cloud — Unlimited Free Cloud Storage (Flutter Android App)

> **UnLim Cloud** হলো একটি আধুনিক, দ্রুতগতির এবং ওপেন-সোর্স মোবাইল অ্যাপ্লিকেশন যা টেলিগ্রামের ক্লাউড ইনফ্রাস্ট্রাকচার ব্যবহার করে সম্পূর্ণ **ফ্রি এবং আনলিমিটেড ক্লাউড স্টোরেজ ড্রাইভ** প্রদান করে।

---

## ✨ প্রধান বৈশিষ্ট্যসমূহ (Features)

1. **♾️ আনলিমিটেড ও ১০০% ফ্রি স্টোরেজ:**
   * কোনো সাবস্ক্রিপশন বা মাসিক ফি ছাড়াই টেলিগ্রাম ক্লাউড স্টোরেজ ব্যবহার করে যত খুশি ফাইল সেভ করুন।
2. **📁 স্মার্ট ফাইল ও ফোল্ডার ম্যানেজার (Virtual Drive):**
   * ভার্চুয়াল ফোল্ডার তৈরি, রিনেম ও ডিলিট করার সুবিধা।
   * ফাইল সর্টিং (তারিখ, সাইজ, নাম) এবং ইনস্ট্যান্ট লাইভ সার্চ।
   * ফেভারিট/স্টার মার্কিং সিস্টেম।
3. **📊 স্টোরেজ অ্যানালিটিক্স ও ড্যাশবোর্ড:**
   * মোট ফাইল সংখ্যা এবং ফটো, ভিডিও, অডিও ও ডকুমেন্টের সাইজের ভিজ্যুয়াল কালার বার ও হিসাব।
4. **⚡ হাই-স্পিড ট্রান্সফার ম্যানেজার:**
   * মাল্টিপল ফাইল আপলোড ও ডাউনলোড প্রগ্রেস বার।
   * ডাউনলোড করা ফাইল সরাসরি ডিভাইসের `Downloads` ফোল্ডারে সেভ হওয়া এবং এক ক্লিকে ওপেন করার অপশন।
5. **🖼️ ফুলস্ক্রিন মিডিয়া ভিউয়ার:**
   * ছবি দেখার জন্য জুম-ইন/জুম-আউট সাপোর্টেড প্রিভিউয়ার এবং শেয়ার অপশন।
6. **🌙 প্রিমিয়াম ডার্ক ও লাইট থিম:**
   * আনলিম (UnLim) স্টাইলের স্লিক ও আধুনিক ডার্ক ইন্টারফেস।
7. **🔒 সম্পূর্ণ নিরাপদ ও ব্যক্তিগত:**
   * ফাইলগুলো আপনার নিজস্ব প্রাইভেট টেলিগ্রাম চ্যানেলে সংরক্ষিত থাকে।

## 🚀 টেলিগ্রাম সংযোগ সেটআপ (মাত্র ২ মিনিট)

1. **টেলিগ্রাম বট তৈরি:**
   * টেলিগ্রামে গিয়ে সার্চ করুন **`@BotFather`**।
   * কমান্ড পাঠান: `/newbot`।
   * আপনার বটের একটি নাম এবং ইউজারনেম দিন (যেমন: `my_cloud_storage_bot`)।
   * BotFather আপনাকে একটি **HTTP API Token** দেবে। সেটি কপি করুন।

2. **প্রাইভেট স্টোরেজ চ্যানেল তৈরি:**
   * টেলিগ্রামে একটি নতুন **Channel** তৈরি করুন এবং সেটিকে **Private** রাখুন।
   * চ্যানেলের সেটিংসে গিয়ে **Administrators** অপশনে আপনার বটকে **Admin** হিসেবে যুক্ত করুন (Post Messages পারমিশন দিন)।

3. **চ্যানেল আইডি সংগ্রহ:**
   * আপনার চ্যানেলে যেকোনো একটি টেস্ট মেসেজ পাঠান।
   * সেই মেসেজটি **`@JsonDumpBot`** অথবা **`@userinfobot`**-এ ফরওয়ার্ড করুন।
   * এটি আপনাকে চ্যানেলের আইডি জানিয়ে দেবে (যেমন: `-1001987654321`)।

4. **অ্যাপে কানেক্ট করুন:**
   * UnLim Cloud অ্যাপের **Settings**-এ যান।
   * আপনার **Bot Token** এবং **Channel ID** পেস্ট করে **"Save & Test Connection"** চাপুন। ব্যাস, আপনার ক্লাউড ড্রাইভ প্রস্তুত!

## 📦 কীভাবে অ্যান্ড্রয়েড APK (Android APK) বিল্ড করবেন?

### মেথড ১: GitHub Actions দিয়ে ১-ক্লিকে ফ্রি ক্লাউড বিল্ড (সবচেয়ে সহজ — কোনো পিসি লাগবে না!)
প্রজেক্টে ইতিমধ্যেই সম্পূর্ণ রেডিমেড **`.github/workflows/build_apk.yml`** ফাইল কনফিগার করা আছে:
1. আপনার টারমাক্সে গিট রিপোজিটরি ইনিশিয়ালাইজ করুন:
   ```bash
   git init
   git add .
   git commit -m "Initial commit for UnLim Cloud Flutter app"
   ```
2. আপনার GitHub অ্যাকাউন্টে একটি নতুন রিপোজিটরি বানিয়ে পুশ করুন:
   ```bash
   git branch -M main
   git remote add origin https://github.com/<your-username>/<your-repo-name>.git
   git push -u origin main
   ```
3. গিটহাবে পুশ করার সাথে সাথে **GitHub Actions** স্বয়ংক্রিয়ভাবে ক্লাউডে আপনার জন্য সম্পূর্ণ অপ্টিমাইজড **`app-release.apk`** তৈরি করে দেবে! আপনি GitHub-এর **Actions -> Artifacts** থেকে সরাসরি ডাউনলোড করে আপনার অ্যান্ড্রয়েড ফোনে ইনস্টল করতে পারবেন!

---

### মেথড ২: লোকাল পিসিতে বিল্ড
যদি আপনার পিসিতে Flutter SDK থাকে:
```bash
flutter pub get
flutter build apk --release
```
বিল্ড হওয়া APK ফাইলটি পাবেন: `build/app/outputs/flutter-apk/app-release.apk`
